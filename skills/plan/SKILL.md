---
name: plan
description: Survey the repository and produce a numbered implementation plan with explicit success criteria before any code changes; then stop and wait for approval.
whenToUse: When the user asks to plan, or before starting any non-trivial implementation.
---
Analyze the repository and produce a concise implementation plan. Do NOT edit any files yet.

Deliver: (1) a brief summary of the relevant architecture, (2) a numbered implementation plan with exact file paths and the change per file, (3) explicit success criteria, (4) assumptions and open questions.

Then STOP and wait for human approval before making any changes.
